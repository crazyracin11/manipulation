## 项目概览

本项目是一个基于 **MuJoCo Playground** 的灵巧操作强化学习项目，使用 **PPO (Proximal Policy Optimization)** 算法训练 LEAP 机械手进行立方体重定向任务。

**核心特征：**
- 框架：JAX + Brax + MuJoCo MJX
- 环境：LeapCubeReorient（立方体在 SO(3) 空间重定向）
- 算法：PPO（非对称观察，actor 使用感觉状态，critic 使用特权状态）
- 训练规模：8192 并行环境，2亿步训练

### 3. 奖励函数

**配置位置**：`reorient.py` 的 `default_config()` 函数（第 51-62 行）

```python
reward_config:
  scales:
    orientation: 5.0        # 姿态匹配奖励（主要）
    position: 0.5           # 位置对齐奖励
    hand_pose: -0.5         # 手部姿态正则化（惩罚）
    action_rate: -0.001     # 动作平滑（惩罚抖动）
    energy: -0.001          # 能量消耗（惩罚）
    joint_vel: 0.0          # 关节速度（未使用）
    termination: -100.0     # 失败惩罚
  success_reward: 100.0     # 成功时额外奖励
```

**姿态奖励计算** (`reorient.py` 第 422-424 行)：
```python
def _reward_cube_orientation(self, data):
    ori_error = self._cube_orientation_error(data)
    # 使用 tolerance 函数：误差越小奖励越高
    return reward.tolerance(ori_error, (0, 0.2), margin=jp.pi, sigmoid="linear")
```

**位置奖励计算** (`reorient.py` 第 385-388 行)：
```python
cube_pos = self.get_cube_position(data)
palm_pos = self.get_palm_position(data)
cube_pose_mse = jp.linalg.norm(palm_pos - cube_pos)
cube_pos_reward = reward.tolerance(
    cube_pose_mse, (0, 0.02), margin=0.05, sigmoid="linear"
)
```

**总奖励计算** (`reorient.py` 第 228-248 行)：
```python
# 各项奖励 × 权重
rewards = {
    k: v * self._config.reward_config.scales[k]
    for k, v in rewards.items()
}
reward = sum(rewards.values()) * self.dt

# 成功时额外奖励
reward += success * self._config.reward_config.success_reward
```

**特权观察**（Critic 专用，无噪声）：
```python
privileged_state = jp.concatenate([
    state,
    data.qpos[self._hand_qids],        # 真实关节位置
    data.qvel[self._hand_dqids],       # 真实关节速度

```
